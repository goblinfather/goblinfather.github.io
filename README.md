# Taehun Ki — Professional Portfolio

A static, responsive professional portfolio hosted on GitHub Pages.

- Business technology, data and AI enablement
- Independent engineering research: ReconGuard
- High-level professional case studies and career history
- Accessible navigation, responsive layout, system/default color themes and no third-party dependencies

## Preview

Open index.html in a browser or run `python -m http.server 8000` locally and visit http://localhost:8000.

## Content policy

Professional case studies intentionally omit non-public business KPIs, customer data, internal system designs and private employment matters. Independent project results distinguish functional tests from detection accuracy and actual operational impact. Employment titles and education follow the 2026 CV. Personal phone numbers and the private CV are not distributed with the site.

## Structure

- index.html — page content and semantic layout
- style.css — design system and responsive styles
- main.js — optional accessible theme switch

Legacy assets remain in repository history and are not required by the refreshed page.
